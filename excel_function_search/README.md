# Excel関数検索ツール

## 概要

関数名を知らなくても、やりたいことやキーワードからExcel関数を探せるツールです。使い方、引数、数式例を確認できます。

## 主な機能

- 関数名・用途・キーワードで検索
- カテゴリと用途による絞り込み
- 数式例・引数説明・対応版と基本ガイドの表示

## 使い方

検索欄にやりたいことを入力するか、カテゴリを選びます。候補から関数を選び、数式例と説明を確認します。

## 起動・体験

[**Excel関数検索ツールを開く**](https://yumin-snoopy.github.io/tools/excel_function_search/)
