数式の基本・セル参照・エラーの読み方

数式は半角の = から始めます。引数とは、括弧の中に渡す値や範囲のことです。半角カンマで順番に区切ります。地域設定によって区切りがセミコロンになる環境もあります。

  • A2：A列の2行目。A2:A5：A2からA5までの4セルです。
  • $A$2：コピーしても列・行を固定。A$2は行、$A2は列だけを固定します。
  • 文字："営業"のように半角の二重引用符で囲みます。数値80やセル参照A2には付けません。
  • TRUE / FALSE：成立 / 不成立の論理値。1 / 0で指定できる引数もあります。
  • [] と …：[]は省略可、…は繰り返し可。実際の数式にはこの記号を入力しません。途中の任意引数を省略するときはカンマを残します。
  • 空白と ""：未入力のセルと、数式が返す空文字は異なります。COUNTAやISBLANKの判定も変わります。
  • #N/A：該当値なし。#VALUE!：値・型・引数の指定を確認。#REF!：参照先が無効。#DIV/0!：0で割っている。
  • #NAME?：関数名・名前・対応版を確認。#NUM!：数値の範囲や計算条件を確認。#SPILL!：配列の出力先を空け、テーブルの外に式を置く。#CALC!：空配列やLAMBDAの呼び出しを確認。

例えば =TEXTBEFORE(A2,"-",,,1) は、出現番号と一致モードを省略し、末尾一致だけに1を指定しています。各関数の詳細にある「省略した場合」で動作を確認できます。
