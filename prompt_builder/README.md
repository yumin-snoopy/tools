# プロンプト作成支援ツール

## 概要

用途や目的、条件を入力し、生成AIに渡すお願いの文章を組み立てるツールです。入力した内容はブラウザ内で処理します。

## 主な機能

- 用途・対象者・条件・出力形式の指定
- サンプル入力と生成結果の編集
- 完成した文章のコピーとクリア

## 使い方

用途と目的を入力し、必要な条件を選びます。生成した文章を確認・編集してコピーし、利用するAIに貼り付けます。

## 起動・体験

[**プロンプト作成支援ツールを開く**](https://yumin-snoopy.github.io/tools/prompt_builder/)
