# 便利Webツール

日常の作業を少し便利にするWebアプリをまとめたリポジトリです。
HTML・CSS・JavaScriptのみで動作し、サーバーやデータベースは不要です。

## 現在のツール

- **文章整形ツール** (`text_formatter/index.html`)：空白・空行・改行の削除、全角英数字の半角変換、行頭・行末の空白削除、Markdownの太字記号削除。複数処理の一括実行、文字数表示、コピー、確認付きクリアに対応しています。

文章はブラウザー内で処理します。外部への送信やブラウザーへの保存はしません。

## GitHub Pagesで利用する

1. このフォルダの**中身**を `tools` リポジトリのルートに配置します（`tools/tools/` にしないでください）。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. **Branch** に `main`、フォルダに **/(root)** を選んで **Save** を押します。
5. デプロイ完了後、Pages画面に表示されたURLから利用できます。

`yumin-snoopy/tools` として公開した場合のURL：<https://yumin-snoopy.github.io/tools/>（公開設定・デプロイ完了後に利用できます）

## 構成

```text
tools/
├─ index.html
├─ README.md
└─ text_formatter/
   ├─ index.html
   ├─ style.css
   └─ script.js
```

トップページも `text_formatter/style.css` の共通スタイルを利用しています。
外部ライブラリ、外部フォント、解析サービスは使用していません。

## 文章整形の仕様

- 元の文章を残し、別の欄に整形結果を表示します。入力や設定を変えると古い結果を消します。
- 初期選択：行頭・行末の空白削除、連続した半角スペースの整理、太字記号の削除。
- 「文章内の余分な空白を削除」は、半角・全角スペースとタブなどの横方向の空白をすべて削除します。英単語間の空白も消えるため、必要なときだけ選択してください。
- 「改行を削除」は、区切り文字を追加せずに各行を結合します。
- 処理順：全角英数字変換 → 太字記号削除 → 行頭・行末の空白削除 → 空行削除 → 改行削除 → 連続半角スペース整理 → 全空白削除。選択した処理のみ実行します。
- 文字数は改行を除いたUnicodeコードポイント数です。「空白を除いた文字数」はスペース・タブなども除きます。絵文字の結合文字は別々に数えます。
- 空文字の行数は0です。末尾の改行でできる空行も1行として数えます。
- コピーはClipboard APIを利用し、未対応・拒否時は従来のコピー方法を試します。どちらも使えない場合は手動コピーの案内を表示します。
