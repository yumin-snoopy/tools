# 便利Webツール（tools）

日常の作業に使えるブラウザ用ツールをまとめています。名前をクリックすると各ツールの説明が開きます。

| 名前 | 概要 |
| --- | --- |
| [Excel関数検索ツール](excel_function_search/README.md) | 関数名を知らなくても、やりたいことやキーワードからExcel関数を探せるツールです。 |
| [かんたん画像リサイズ・圧縮](image_resizer/README.md) | 画像の横幅と保存形式を選んで、容量を調整するツールです。 |
| [プロンプト作成支援ツール](prompt_builder/README.md) | 用途や目的、条件を入力し、生成AIに渡すお願いの文章を組み立てるツールです。 |
| [QRコード作成ツール](qr_generator/README.md) | URLや文章を入力し、QRコードを作ってPNG画像で保存するツールです。 |
| [文章整形ツール](text_formatter/README.md) | 文章を貼り付け、空白・空行・改行などを必要に応じて整えるツールです。 |
