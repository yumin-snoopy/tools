# 便利Webツール

日常の作業を少し便利にするWebアプリをまとめたリポジトリです。
HTML・CSS・JavaScriptのみで動作し、サーバーやデータベースは不要です。

## 現在のツール

- **文章整形ツール** (`text_formatter/index.html`)：空白・空行・改行の削除、全角英数字の半角変換、行頭・行末の空白削除、Markdownの太字記号削除。複数処理の一括実行、文字数表示、コピー、確認付きクリアに対応しています。
- **QRコード作成ツール** (`qr_generator/index.html`)：URL・日本語文章・メールアドレス・電話番号などからQRコードを作成します。小・中・大のサイズ選択、配色設定、PNG保存、初期状態へのクリアに対応しています。

- **プロンプト作成支援ツール** (`prompt_builder/`)：用途・目的・対象者・元の文章・条件・出力形式から、生成AIに伝わりやすいプロンプトを作成します。サンプル入力、生成結果の編集、コピー、クリアに対応しています。

文章はブラウザー内で処理します。外部への送信やブラウザーへの保存はしません。

## GitHub Pagesで利用する

1. このフォルダの**中身**を `tools` リポジトリのルートに配置します（`tools/tools/` にしないでください）。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment → Source** を **Deploy from a branch** にします。
4. **Branch** に `main`、フォルダに **/(root)** を選んで **Save** を押します。
5. デプロイ完了後、Pages画面に表示されたURLから利用できます。

`yumin-snoopy/tools` として公開した場合のURL：<https://yumin-snoopy.github.io/tools/>（公開設定・デプロイ完了後に利用できます）

トップページも `text_formatter/style.css` の共通スタイルを利用しています。
外部フォント、解析サービスは使用していません。

## QRコード作成の仕様とライブラリ

- [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) 1.4.4（Kazuhiko Arase、MITライセンス）を `qr_generator/vendor/` に同梱しています。CDNへの通信は不要です。UTF-8対応ファイルで日本語・絵文字を処理します。
- 入力内容を変更・送信・保存せず、そのままQRコードにします。電話番号やメールアドレスも文字列として扱います。発信・メール起動用には `tel:` / `mailto:` を入力してください。
- 誤り訂正レベルM、4モジュール以上の余白、整数ピクセル描画を使用します。配色は明るい背景・暗い前景・コントラスト比7以上に制限しますが、すべての読み取り機器での動作を保証するものではありません。
- 300文字を超えると注意を表示します。容量超過や細かすぎるQRコードは作成せず、内容短縮やサイズ変更を案内します。
- 入力・サイズ・配色の変更時には古いQRを消します。保存画像は選択したサイズの `qr-code.png` です。クリアはサイズ・配色も初期状態へ戻します。
- 各ページで右クリックやソース表示のショートカットを簡易的に抑止します。入力欄ではコピー・貼り付けを優先します。HTMLやJavaScriptの完全な秘匿はできず、ブラウザーのメニュー・開発者機能・GitHubから閲覧できます。

## 文章整形の仕様

- 元の文章を残し、別の欄に整形結果を表示します。入力や設定を変えると古い結果を消します。
- 初期選択：行頭・行末の空白削除、連続した半角スペースの整理、太字記号の削除。
- 「文章内の余分な空白を削除」は、半角・全角スペースとタブなどの横方向の空白をすべて削除します。英単語間の空白も消えるため、必要なときだけ選択してください。
- 「改行を削除」は、区切り文字を追加せずに各行を結合します。
- 処理順：全角英数字変換 → 太字記号削除 → 行頭・行末の空白削除 → 空行削除 → 改行削除 → 連続半角スペース整理 → 全空白削除。選択した処理のみ実行します。
- 文字数は改行を除いたUnicodeコードポイント数です。「空白を除いた文字数」はスペース・タブなども除きます。絵文字の結合文字は別々に数えます。
- 空文字の行数は0です。末尾の改行でできる空行も1行として数えます。
- コピーはClipboard APIを利用し、未対応・拒否時は従来のコピー方法を試します。どちらも使えない場合は手動コピーの案内を表示します。

## プロンプト作成の仕様

- 用途は9種類から選択できます。目的は必須、ほかの入力・選択は任意です。対象者は候補からの選択と自由入力に対応しています。
- 条件は複数選択でき、出力形式は文章・箇条書き・表・手順・メール・自由から選べます。相反する条件や出力形式の組み合わせは、見直しの案内を表示します。
- 選択した用途に応じた「役割」と、入力済みの項目だけを見出し付きで出力します。「その他」や未選択の用途では役割を追加しません。
- 「サンプルを入力」は、取引先への納期遅延のお詫びメールと3つの条件、メール形式をセットします。作成ボタンで完成例を確認できます。
- 生成結果は編集可能です。入力を変更すると再作成の案内が出ます。再作成は結果欄の編集内容を上書きします。クリアは結果・選択条件も初期状態に戻します。
- コピーはClipboard APIを使い、利用できない場合は従来のコピー方法を試します。失敗時は手動コピーを案内します。コピーするのは結果欄の現在の文章です。
- 生成AIのAPI・外部ライブラリ・サーバー・データベースは使用しません。作成した文章を利用者がChatGPTなどへ貼り付けて使用します。
- 既存の共通CSSと `source-guard.js` を利用します。右クリック・ソース表示のショートカットを簡易抑止しますが、ソースの完全な秘匿はできません。入力欄のコピー・貼り付けは利用できます。
