# QRコード作成ツール

## 概要

URLや文章を入力し、QRコードを作ってPNG画像で保存するツールです。入力内容はブラウザ内で処理します。

## 主な機能

- 小・中・大のサイズ選択
- 色の設定と読み取りにくい配色の確認
- PNG保存と入力・設定のクリア

## 使い方

URLや文章を入力し、サイズを選んで「QRコードを作成する」を押します。表示を確認して「QRコードを保存」を押します。

## 起動・体験

[**QRコード作成ツールを開く**](https://yumin-snoopy.github.io/tools/qr_generator/)

## 使用技術

HTML・CSS・JavaScript
