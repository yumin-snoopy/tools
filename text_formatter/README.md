# 文章整形ツール

## 概要

文章を貼り付け、空白・空行・改行などを必要に応じて整えるツールです。元の文章を残したまま結果を表示します。

## 主な機能

- 複数の整形処理を選んで一括実行
- 全角英数字の半角変換とMarkdown太字記号の削除
- 文字数・行数表示、コピー、クリア

## 使い方

文章を貼り付け、使いたい整形項目にチェックを入れます。「文章を整形する」を押し、結果を確認してコピーします。
