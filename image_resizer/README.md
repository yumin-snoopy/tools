# かんたん画像リサイズ・圧縮

## 概要

パソコン初心者でも画像の横幅と容量を簡単に変更できる、GitHub Pages向けの静的ツールです。

## 主な機能

- ドラッグ＆ドロップまたはファイル選択で画像を読み込み
- 元画像と変換後のプレビュー、画像サイズ、ファイル容量を表示
- 1280 / 1000 / 800 / 640pxのプリセットと自由入力で横幅を指定
- 縦横比を維持して変換し、元画像より大きくはしない
- JPG / WebPの画質を50〜100%で指定（PNGは画質指定なし）
- JPG / PNG / WebPで保存
- 変換前後の容量と削減率を表示
- リセット、不正な画像のエラー表示

## 対応画像形式

読み込み・保存ともにJPG（JPEG）、PNG、WebPに対応します。ブラウザがその形式の画像を扱える必要があります。透明な画像をJPGにすると、透明な部分は白になります。

## 使い方

1. `index.html`をブラウザで開きます。
2. 画像をドロップするか、「画像を選択」で読み込みます。
3. 横幅、画質、保存形式を選びます。
4. 「画像を変換する」を押して結果を確認します。
5. 「保存する」を押してダウンロードします。

画像の読み込み、変換、保存はCanvas APIを使い、すべてブラウザ内で行います。画像データを外部へ送信しません。サーバー、外部API、外部ライブラリは使いません。`file://`で開く場合も、GitHub Pages上でも動作します。

## GitHub Pagesの公開URL

公開後に記入：`https://yumin-snoopy.github.io/tools/image_resizer/`

GitHub Pagesが`main`ブランチのルートを公開している場合、`tools`リポジトリのルートに`image_resizer`フォルダを配置すると上記URLになります。
