# かんたん画像リサイズ・圧縮

## 概要

画像の横幅と保存形式を選んで、容量を調整するツールです。画像はブラウザ内で処理します。

## 主な機能

- ファイル選択・ドラッグ＆ドロップ
- 横幅・画質・JPG/PNG/WebP の選択
- 変換前後のサイズ・容量比較と保存

## 使い方

画像を選び、横幅と形式を指定して「画像を変換する」を押します。結果を確認して「保存する」でダウンロードします。
